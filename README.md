# Random Activity Guesser

A simple Python application that helps you choose between multiple options by spinning a visual roulette wheel. Just enter your choices, spin the wheel, and let the program randomly select a winner.

## Features

* Add between 2 and 18 options
* Interactive spinning roulette animation
* Random winner selection
* Spin again without re-entering all options
* Easy-to-use interface

## Built With

* Python 3
* Turtle Graphics
* Random module

## How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/ZorovsKilua/Choice-maker.git
   ```

2. Open the project folder:

   ```bash
   cd your-repository
   ```

3. Run the program:

   ```bash
   python main.py
   ```

## Requirements

* Python 3.x
* No external libraries are required.

## Example Use

1. Enter how many choices you have (between 2 and 18).
2. Type each option.
3. Spin the roulette.
4. The program randomly selects a winner.
